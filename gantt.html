El guardado local permanece en este navegador. Guarda una copia JSON o CSV para mover tu plan a otro equipo.

Un plan que puedes tocar

Arrastra una barra para cambiar sus fechas. Arrastra los extremos para ajustar la duración. Haz doble clic en la barra o pulsa el nombre para editar.

Las flechas muestran dependencias de fin a inicio. Las fechas se ajustan manualmente; los conflictos se indican bajo la vista.

Formato de importación

CSV UTF-8 con cabecera: id,name,start,end,progress,owner,group,color,dependencies,milestone,notes,project. Fechas AAAA-MM-DD; progreso de 0 a 100; dependencias separadas por |; hito true/false. Admite comas o punto y coma como separador. Solo name, start y end son obligatorios. Descarga el ejemplo como plantilla.

Hasta 500 tareas y un intervalo máximo de 10 años. JSON conserva también la escala. Las fechas incluyen el día de finalización y cuentan días naturales.
